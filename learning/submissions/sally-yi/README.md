# Sally-yi 六项练习与口述速记

代码由 Codex 辅助完成，公共测试和个人边界案例已实际运行。本人仍需能解释、复跑和现场小改。要求来源为已同步的仓库任务书与公共验收，不修改公共模板。

## 第一个问题的 30 秒回答

**种子管抽签，SHA256 管文件，成员清单管样本。**

只固定种子，相当于只固定抽签方法，没有固定名单。数据、行序、清洗方式或实现环境改变，测试样本仍可能不同。我会核对原始 CSV 的 SHA256，锁定代码、依赖、参数和分组规则，再逐项比较分区原行位置及内容指纹，确认组不跨区、全行恰好覆盖一次、特征标签逐行对应。**行数一样，只能说明人数一样，不能证明是同一批人。**

本项目：训练 **104974**、验证 **22518**、测试 **22508** 行。记住 **7／1.5／1.5 是按组的目标比例**，行数有小偏差正常。

## 六题只先背这张表

顺序：**查缺 → 分区 → 看排序 → 算箱差 → 换评分 → 比模型。**

| 函数 | 一句话记忆 | 小样本答案 |
| --- | --- | --- |
| `missing_rate` | 缺失个数除以总行数；0 有效 | `[1, NaN]` → 0.5，即50% |
| `split_three_way` | 先绑组，再分7／1.5／1.5；返回行位置 | 200组×2行 → 280／60／60行 |
| `roc_auc_manual` | 正负配对：赢1，平半，输0，再平均 | 四次得分1、0、1、1 → 0.75 |
| `woe_iv_from_counts` | 好坏各算占比；WOE取对数比，IV把“占比差×WOE”加总 | `[8,2]`对`[2,8]`：WOE约±1.2238，IV约1.335028 |
| `probability_to_score` | 风险升、分数降；好坏比翻倍加PDO | 20:1 →600；40:1 →620；10:1 →580 |
| `compare_models` | 同样本同标签；AUC看排序，Brier看误差，混淆矩阵看阈值 | 甲AUC=.75、Brier=.158125；乙1、.0875 |

## 三个最容易说错的地方

- **组最大标签仅用于分层，不改原始 y。** 同一输入的行必须放在一个分区。
- **AUC 不等于准确率。** AUC比较正负排序；准确率先按阈值判0/1。单改阈值不改变AUC、Brier。
- **好坏比=(1-p)/p。** p是严重逾期概率；600分对应p=1/21。用信用分评价严重逾期时，注意高分代表低风险。

## 怎么打开与运行

打开本目录的 [exercises.py](exercises.py) 看代码，[test_personal.py](test_personal.py) 看手算边界，[口述备答](口述备答.md) 看老师追问的逐项回答。源码只需先读六个主函数；下划线函数是输入校验或数值稳定处理。

在仓库根目录运行（解释器路径换成自己的）：

```powershell
.venv/Scripts/python.exe tools/exercises.py check Sally-yi
.venv/Scripts/python.exe tools/exercises.py demo Sally-yi
```

当前答案目录按工具统一为小写 `learning/submissions/sally-yi/`。本机实际使用已有的 Python 3.11.17 项目环境；提交没有包含虚拟环境或原始数据。

## 每天三分钟

先遮住表格右栏，口述每题一句话；再手算AUC的四个配对、600/620/580三个分数；最后回答：“为什么行数一样还不够？”如果讲不出理由，就看备答里的对应小节，再自己说一遍。
