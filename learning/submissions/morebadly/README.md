## 手算与例子核对

### E01 missing_rate

逐列缺失率=该列缺失数量/行数，保持输入列顺序，0是有效值。三行 `[0, NaN, 1]` 的缺失率为1/3；`[NaN, 0, NaN]` 为2/3。返回带列名的Series，不修改原表。空表没有有效分母，明确抛ValueError；浮点1/3、2/3用近似比较。

### E02 split_three_way

组标签取组内原始y的最大值，仅用于分层。按组先70%/30%，再把剩余组等分，两次使用同一seed42；返回原始行位置数组。

200组、每组2行，共400行：训练140组×2=280行、验证30组×2=60行、测试30组×2=60行。组大小不等时仍按组目标140/30/30，行数比例允许偏差。验收同时检查全行恰好覆盖一次、组间无交集、每区两类及重复运行一致；不把组内每行标签改成组最大标签。

### E03 roc_auc_manual

对y=`[0,0,1,1]`，概率=`[.1,.4,.35,.8]`，正样本.35分别对负样本.1/.4得1/0；正样本.8得1/1。因此AUC=(1+0+1+1)/4=0.75。同分给0.5，所有分数相同得到0.5。

个人并列例：负样本.2/.5，正样本.2/.8，四次比较为0.5、0、1、1，AUC=2.5/4=0.625。本函数直接比较正负两两分数，不调用库的AUC或曲线面积函数；复杂度O(正类数×负类数)，用于小样本教学。

### E04 woe_iv_from_counts

good=[8,2]、bad=[2,8]、alpha=0.5，K=2，两类总数均为10。平滑后分母均为10+0.5×2=11：

```text
pg = [8.5/11, 2.5/11]
pb = [2.5/11, 8.5/11]
WOE = [ln(3.4), -ln(3.4)] ≈ [1.223775432, -1.223775432]
IV = (6/11)*ln(3.4) + (-6/11)*(-ln(3.4))
   = (12/11)*ln(3.4) ≈ 1.335027744
```

分子、分母一起平滑，两类分布各自和为1；零频箱保持有限。个人新增三箱例good=[10,0,0]、bad=[0,10,0]检查这一性质，第三箱WOE为0。该alpha公式是课堂定义，不能当作团队OptBinning原生WOE/IV的默认公式。

### E05 probability_to_score

```text
O = (1-p)/p
Factor = PDO/ln(2)
Offset = BaseScore - Factor*ln(BaseOdds)
Score = BaseScore + Factor*(ln(O)-ln(BaseOdds))
```

默认BaseScore600、BaseOdds20、PDO20：p=1/21时O=20，分数600；p=1/41时O=40，分数620；p=1/11时O=10，分数580。自选p=0.12，好坏比翻倍的新概率为p/(2-p)=3/47，评分增加Factor×ln2=20，测试核对该差值。

使用稳定的 `log1p(-p)-log(p)`，不提前取整。标量返回float，数组保持形状；p=0/1直接拒绝，不静默截断。极端合法概率仍可计算；参数导致最终分数溢出时明确报错。

### E06 compare_models

使用同一批四条人工样本和同一标签方向，阈值由调用方给定，函数内不搜索阈值；分类规则是p>=threshold。

| 合成模型 | 固定阈值 | AUC | Brier | TN/FP/FN/TP |
| --- | ---: | ---: | ---: | --- |
| a，概率[.1,.4,.35,.8] | .4 | .75 | .158125 | 1/1/1/1 |
| b，概率[.15,.25,.55,.75] | .5 | 1 | .0875 | 2/0/0/2 |

a的Brier=(.1²+.4²+(.35-1)²+(.8-1)²)/4=.6325/4=.158125；b为(.0225+.0625+.2025+.0625)/4=.0875。a中y=0、p=.4的一行按等号归正类，因此是FP。

个人测试把a阈值改成.5，混淆矩阵变为2/0/1/1，AUC与Brier保持不变。输出保持模型输入顺序；当y与概率都是Series时，索引顺序错位会被拒绝。
