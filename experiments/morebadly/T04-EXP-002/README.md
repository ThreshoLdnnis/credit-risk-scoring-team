2026-10-29，基于杨曦（Clement-xi）的 [PR #12](https://github.com/ThreshoLdnnis/credit-risk-scoring-team/pull/12)，郭宇哲（morebadly）在用户授权下补充边界修复、回归测试及真实实验证据。完整 C 模板记录见 [record.json](record.json)，原生逐箱聚合表见 [binning_evidence.json](binning_evidence.json)。本地运行源码版本 `4acb1e9ffa7ba7e01db29085ec6c1e097e2bb54e`，逐文件 SHA256 可核对送审内容。

## T04 要求及本次补充

T04 要求训练内监督分箱、OptBinning 原生 WOE/IV、按 IV 选择变量、L2 LR、违约概率和信用分，以及 BaseScore=600、好坏比20:1、PDO=20 和浮点分项加和。评分卡原实现归属 Clement-xi；本次补充 Series 标签必须与输入行对齐、复数特征拒绝、LR 收敛失败不能返回成功，并补齐完整固定阈值指标及阈值配置协议校验。

训练全缺失或非缺失值恒定的列排除并赋零分；未在训练中见过的缺失映射到0 WOE，其他缺失使用已拟合的原生 missing bin。推理不重新分箱或拟合。概率数值饱和时信用分仍从有限原始 log-odds 计算，不裁剪概率；这些边界已有测试。

## 指定数据可用性

**数据可用，校验通过。** `cs-training.csv` 共150,000行、12个原始字段。文件从已记录的公开镜像取得，原始字节 SHA256 为 `1bd46da486a5708c58c7b01a034fae2a13b327f6f7b62ea7ba4fe3b5824b24ac`，与T02官方文件完全一致。

复用 T02 清洗和13列内容组划分，seed=42。训练/验证/测试分别104,974/22,518/22,508行，成员位置与此前T03保存的分区完全一致，组交集为0。标签和序号不入模；没有删行或额外截断极端值。

13个分箱求解状态均为 **OPTIMAL**，按训练 IV≥0.02 保留10个原始特征。逐箱好坏计数合计与训练标签一致，原生WOE方向手算核对最大误差 `5.55e-16`，未使用课堂alpha平滑。LR在15次迭代内收敛。
