# T06：供页面主责接入的解释接口

郭宇哲（morebadly）负责解释模块，杨曦负责页面；本说明关联 [Issue #6](https://github.com/ThreshoLdnnis/credit-risk-scoring-team/issues/6)。使用约定的两参数接口，不改共享配置、训练入口和 `app.py`。

```python
from src.data import clean_features
from src.explanation import explain_tree
from src.tree_model import predict_tree

# bundle 为共享入口保存的 tree.joblib；raw_input 为已校验的10列原始输入。
features = clean_features(raw_input)
probability = predict_tree(bundle, features)
explanation = explain_tree(bundle, features)
# 可直接 st.json(explanation)，数值列表均可 JSON 序列化。
```

| 返回字段 | 形状/含义 |
| --- | --- |
| `base_log_odds` | n 个基础值，单位 log-odds |
| `shap_values` | n×13 个正类贡献，顺序对应 `feature_names` |
| `raw_log_odds` | n 个模型原始输出 |
| `probability` | n 个 y=1 概率，与离线预测同序 |
| `feature_names` | 全部13列，固定训练列顺序 |
| `row_index_repr` | 输入索引的字符串表示，供顺序核对 |
| `metadata` | 解释器、版本、最佳轮数、背景来源、误差与单位 |

接口核验 `base_log_odds + sum(shap_values) = raw_log_odds`（绝对容差 1e-6）和 `sigmoid(raw_log_odds) = predict_tree(...)`（绝对容差 1e-10）；不满足时抛出错误。空表、字段缺失/多列/重复、非数值、无穷、复数和非法 bundle 均拒绝，NaN 按树模型原生策略处理。不会再次训练模型或改变阈值。

解释的是已冻结 `best_iteration` 的正类原始 log-odds。解释器显式设为 `shap.TreeExplainer(model_output='raw', feature_perturbation='tree_path_dependent')`：背景分布来自训练时保存在树中的路径/叶节点样本计数，不传入验证/测试行作为背景，也没有另外抽取显式 interventional 背景。用切到最佳轮数的独立 Booster，保留 binary 目标参数，避免后续轮数与解释不一致。SHAP 0.46 的二元输出形状在模块内统一为正类矩阵。

页面接入时，请将 tree 加入可加载模型选项，仅在真实 tree bundle、有效输入和解释依赖都可用时调用；继续保留无模型/无解释与异常提示。`render_explanation_panel` 原有的 `explainer(bundle, features)` 调用可直接使用本接口。解释成功后，将面板的 `available` 按实际状态置为 True；旧的“树模型/解释模块未实现”提示也由页面主责同步修订。

局部图展示前8个绝对贡献最大的特征时，必须补一个其余5列贡献的有符号总和；再由基础值累计到最终 raw log-odds。红色正贡献增加模型的严重逾期倾向，蓝色负贡献降低倾向；贡献不能写成概率百分点、信用分或因果效应。全局 `mean(abs(SHAP))` 只描述指定解释样本，无法说明方向或因果关系。

## 复验工具的结果判定

保存的逐行 CSV 是历史实验的核对依据：脚本仍要求它重算出的指标在 `1e-12` 内一致、验证阈值在 `1e-14` 内一致。重载模型的逐行概率仍使用原有 `1e-14` 容差；超出容差、原始指标错误、源码/产物哈希错误均继续拒绝，不通过放宽标准掩盖变化。

极小概率变化可能打破并列，改变 AUC/AP 等排序指标。工具使用原冻结阈值重算重载结果，将差异保存在 `models[模型名].reloaded_metric_differences`，同时记录逐行概率最大差、变化行数和重载后的全部指标。`all_metrics_reproduce` 只有在重载指标也满足 `1e-12` 时才为 true。重新计算的验证候选阈值仅供诊断，不替换原阈值。

如重载指标或验证候选阈值有差异，汇总状态为 `completed_audit_with_reloaded_numeric_differences`，并列出 `models_with_reloaded_differences`。这表示历史记录和逐行推理校验已完成，但存在明确记录的数值差异，不能描述为所有重载指标完全相同。原实验记录不被覆盖，SHAP 仍基于已冻结的树模型计算。

背景定义依据 [SHAP TreeExplainer 文档](https://shap.readthedocs.io/en/stable/generated/shap.TreeExplainer.html)；有效轮数推理依据 [LightGBM 4.5 Booster API](https://lightgbm.readthedocs.io/en/v4.5.0/pythonapi/lightgbm.Booster.html)。本工程固定使用 SHAP 0.46.0、LightGBM 4.5.0，并用本地固定版本的实际输出验证。
