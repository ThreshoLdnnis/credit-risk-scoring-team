# 团队真实实验记录

每次复制 `template.json` 到 `experiments/本人GitHub用户名/EXP-001/record.json`，实际运行后填写。实验编号在本人目录中递增；文件放到各自目录，避免相互覆盖。

记录真实的数据 SHA256、处理、分区、参数、指标、代码 SHA、运行命令、输出位置和问题。没有运行的指标保留 null，并说明原因；结果不能复制自负责人个人项目或文章。

大型模型、完整预测、数据和图表原始产物保存在本地 `artifacts/本人用户名/EXP-001/`，不提交 Git。可共享的小型汇总与说明随对应实验记录一起审查，最后由负责人汇总到 `reports/final/`。

研究实验只比较相同样本和既定规则。全体保持标签、训练/验证/测试成员及 fit 边界一致。数据从公开样本重新切分不构成新的独立盲测。

可直接复制填写的文字表见 [实验记录模板](../docs/实验记录模板.md)。
