
## E02 分组分层三段切分

```text
split_three_way(y, groups, seed=42)
    -> dict[str, np.ndarray]
```

输入为一维 0/1 标签，以及等长、无缺失的组标识。输出包含三个键：train、validation、test；对应数组保存原始行位置，可用 iloc 选取记录。

先形成每组一个标签的表，组标签取该组 y 的最大值，仅用于分层。先划分训练组与剩余组，再将剩余组等分为验证与测试。两次种子相同；每区都须包含两类。

| 检查 | 要求 |
| --- | --- |
| 覆盖 | 所有原始行恰好出现一次 |
| 隔离 | 三组的组标识交集为空 |
| 复现 | 相同输入和种子返回相同位置数组 |
| 比例 | 按组目标 70/15/15，行比例允许小偏差 |

测试例有 200 个组、每组 2 行，共 400 行；预期为 280、60、60 行。另一例组大小不等，检查组数 140、30、30，不强制相同的行数比例。

## E03 用两两比较计算 AUC

```text
roc_auc_manual(y, probability) -> float
```

输入等长一维向量，标签同时包含 0 与 1，概率有限且在 [0,1] 内。输出正样本分数高于负样本的平均得分；同分给 0.5。无效输入抛 ValueError。

| 标签 y | 0 | 0 | 1 | 1 |
| --- | --- | --- | --- | --- |
| 概率 | 0.10 | 0.40 | 0.35 | 0.80 |

先把两个正样本分别与两个负样本比较，写出四次比较的 1、0 或 0.5，再取平均。此例 AUC 为 0.75。所有分数相同为 0.5，排序完全正确为 1，完全反向为 0。

### 实现要求

本题自己完成两两比较，不调用库中的 AUC 或曲线面积函数。实现只用于小样本教学；真实大样本评价使用标准库，避免两两比较的计算量过大。

## E04 从好坏计数计算 WOE 和 IV

```text
woe_iv_from_counts(good, bad, alpha=0.5)
    -> tuple[np.ndarray, float]
```

输入同一批训练样本的 K 箱好坏计数。good 对应 y=0，bad 对应 y=1；向量非空、等长、有限非负，两类总数均大于 0，alpha 为有限正数。

```text
pg_i = (G_i+alpha) / (G+alpha*K)
pb_i = (B_i+alpha) / (B+alpha*K)
WOE_i = ln(pg_i / pb_i)
IV = sum((pg_i-pb_i) * WOE_i)
```

用 good=[8,2]、bad=[2,8] 手算，两个分布分别为 [8.5/11,2.5/11] 和 [2.5/11,8.5/11]。WOE 为 ±ln(3.4)，IV 约 1.335028。

### 实现与验收

计算前检查输入；返回 WOE 数组和总 IV。分子与分母一起平滑，检查两组分布各自的和为 1。零频箱也应输出有限数值。

```text
.venv\Scripts\python.exe tools/exercises.py check YOUR_USERNAME --task woe
```

本题是课堂平滑定义，团队评分卡按约定采用 OptBinning 原生规则。你需要说明使用的定义，不能用一个公式的期望值去判断另一套统计约定。

现场解释：为什么分母是所有好样本或坏样本的总数？交换好坏后，WOE 和 IV 分别怎样变化？IV 很高时还应检查哪些问题？

## E05 从概率转换信用分

```text
probability_to_score(probability, base_score=600.0,
                     base_odds=20.0, pdo=20.0)
```

输入为严格位于 (0,1) 的有限概率；标量返回 float，数组保留形状。base_score 有限，base_odds 和 pdo 为有限正数。无效输入抛 ValueError。

```text
O = (1-p) / p
Factor = PDO / ln(2)
Score = Offset + Factor * ln(O)
```

先利用“基准好坏比对应基准分”求出 Offset，再实现映射。不要在函数内提前四舍五入，也不把 0 或 1 悄悄截断。

| 概率 | 好坏比 | 期望分数 |
| --- | --- | --- |
| 1/21 | 20:1 | 600 |
| 1/41 | 40:1 | 620 |
| 1/11 | 10:1 | 580 |

```text
.venv\Scripts\python.exe tools/exercises.py check YOUR_USERNAME --task score
```

测试检查锚点、方向、二维形状、标量类型、参数与概率边界。自选一个概率，计算赔率翻倍后的新概率，再确认评分恰好增加 PDO。

现场解释：为什么风险越高分数越低？改 PDO 会改变 AUC 吗？600 分对应的概率怎样算？
