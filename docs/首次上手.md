# 新成员首次上手

## 1. 接受邀请并克隆

确认自己登录的是收到邀请的 GitHub 账号，接受邀请后访问仓库主页。私人仓库在接受邀请前可能显示 404。

```powershell
git clone https://github.com/ThreshoLdnnis/credit-risk-scoring-team.git
cd credit-risk-scoring-team
git status
```

首次使用 Git 时设置本人提交姓名和邮箱；身份验证在 GitHub 正常登录界面完成。不要在群聊、Issue 或代码中粘贴密码和令牌。

## 2. 建立 Python 3.11 环境

```powershell
python --version
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe -m pip check
.venv\Scripts\python.exe check_environment.py
```

上面均在仓库根目录执行。`python --version` 应为 3.11；若不是，先选择正确的 Python 再建环境。macOS/Linux 将 `.venv\Scripts\python.exe` 换成 `.venv/bin/python`。

安装约束为 `requirements.txt` 与 `constraints.txt`。负责人统一环境锁；组员将本机的 `reports/environment.json` 作为本地排错材料，不互相覆盖同一个环境文件。

## 3. 首次读取官方数据

按官方要求取得 `cs-training.csv` 后放在本地 `data/raw/`，在虚拟环境 Python 中输入：

```python
import pandas as pd
df = pd.read_csv("data/raw/cs-training.csv")
print(df.shape)
print(df.columns.tolist())
print(df["SeriousDlqin2yrs"].value_counts(normalize=True))
print(df.isna().mean())
```

首次读数后，按 [运行与验收](运行与验收.md) 执行 `run_project.py`，再启动 `app.py` 页面。业务模块已接通；个人仍需说明标签、字段与本人模块。

## 4. 按主责开始任务和个人练习

先看 [任务分工](任务认领.md)：吴晓亦负责数据，杨曦负责评分卡与界面，郭宇哲负责模型、评价和解释；再按 [协作约定](../CONTRIBUTING.md) 确认本人的路径。六项练习按 [learning/README.md](../learning/README.md) 创建本人目录，不修改公共模板。

拉取、推送或安装失败时，记录所用命令、完整错误与已尝试的方法，在问题 Issue 中说明；不要反复换环境或照搬另一位组员的虚拟环境目录。
