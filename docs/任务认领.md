## 认领一项任务的方法

1. 在 Issues 新建“模块任务”，填明主责 GitHub 用户名、允许修改的路径、依赖接口和验收。
2. 负责人确认同一个文件没有两位并行主责，再开始任务分支。
3. PR 关联 Issue，展示本人验证；合并后 Issue 关闭，更新进度。

## 共享文件怎样处理

`run_pipeline.py`、`configs/experiment.json`、依赖和根目录 README 经常影响多人，由负责人安排修改顺序。其他组员通过 Issue/PR 提出具体修改，不同时各改一套。最终报告也由一人整合，模型和实验汇总以已审查的实际记录为依据。
