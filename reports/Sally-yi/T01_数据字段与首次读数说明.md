## 字段含义

下表中文业务定义依据本次下载的官方字典。标签的两年预测窗口结合[官方竞赛描述](https://www.kaggle.com/competitions/GiveMeSomeCredit)与团队 `docs/接口约定.md`；字典中标签那一行只说明了 90 天及以上严重逾期，没有单独写出两年。

| 字段 | 用途 | 中文说明 |
| --- | --- | --- |
| `SeriousDlqin2yrs` | 目标标签 | 两年内是否发生 90 天及以上严重逾期；1 为发生，0 为未发生。不是损失金额。 |
| `RevolvingUtilizationOfUnsecuredLines` | 输入特征 | 信用卡及个人信用额度的总余额除以总授信额度；不含房地产债务及汽车贷款等分期债务。原始值按比率读取，例如 0.5 表示 50%。 |
| `age` | 输入特征 | 借款人年龄，单位为年。 |
| `NumberOfTime30-59DaysPastDueNotWorse` | 输入特征 | 过去两年中逾期达到 30 至 59 天、但未达到更严重程度的次数。 |
| `DebtRatio` | 输入特征 | 每月债务偿付、赡养费及生活费用之和，除以月度税前收入。原始值按比率读取。 |
| `MonthlyIncome` | 输入特征 | 月收入。官方字典未说明币种，也未单独注明此列税前或税后口径。 |
| `NumberOfOpenCreditLinesAndLoans` | 输入特征 | 未结清贷款和开放信用额度的数量，包括车贷、房贷等分期贷款及信用卡等信用额度。 |
| `NumberOfTimes90DaysLate` | 输入特征 | 逾期达到 90 天及以上的次数。官方字典没有单独注明此列的回溯期。 |
| `NumberRealEstateLoansOrLines` | 输入特征 | 按揭及房地产贷款数量，包括房屋净值信用额度。 |
| `NumberOfTime60-89DaysPastDueNotWorse` | 输入特征 | 过去两年中逾期达到 60 至 89 天、但未达到更严重程度的次数。 |
| `NumberOfDependents` | 输入特征 | 家庭受扶养人数，不含借款人本人，包括受扶养的配偶、子女等。 |
| `Unnamed: 0` | 导出序号 | 原始 CSV 表头为空，pandas 将其命名为 `Unnamed: 0`；实测为 1 至 150,000 的连续序号，不入模，也不能据此断言是稳定客户 ID。 |

标签是要预测的结果，十个特征是用于预测的信息。标签和导出序号均不能混入模型输入。两个比率字段在原始 CSV 中按数值比率读取，本次不把它们限定到 0 至 1，也不截断极端值。

实际列顺序为序号、标签，再依次为表中十个输入特征。`NumberOfDependents` 的业务含义是人数，本次 pandas 读取为 `float64` 是由于该列含缺失值，并不表示人数可以是小数。
