# 团队模块验收

本目录尚未提供或运行完整系统测试。由团队随实现补充测试，不能把环境导入成功或六项练习通过写成系统已通过验收。

| 模块 | 至少检查 |
| --- | --- |
| 数据 | 缺字段、标签无效、序号排除、规则清洗、输入不被修改、同组不跨区、行覆盖、seed 复现 |
| Baseline | 填补与标准化只在训练 fit；保存加载后概率一致 |
| 评分卡 | 训练内分箱与 IV、零频和缺失/常量策略、求解状态、600/PDO 锚点、分项加和 |
| LightGBM | 验证早停、有效迭代记录、阈值来源、同分区评价 |
| 评价 | 正类方向、对齐、同分 AUC、Brier、p>=threshold、AP 与梯形 PR 面积分别命名 |
| SHAP | 基准加贡献等于 raw_score；sigmoid 后等于概率；记录特征顺序与解释设置 |
| 集成与页面 | 小型合成流程、产物保存加载、非法输入、无模型提示、页面与离线概率及分数一致 |

小规模测试用人工构造数据；真实 Kaggle 实验结果另外记录。新增一次有意义的失败案例，再说明修复和复验结果。
